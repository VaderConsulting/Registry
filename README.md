# Registry

VB6 registry demo from VB-World (`prjRegistry` / `prjRegistry.exe`): wraps advapi32 open/create/delete/query/set helpers in `Registry.bas` and drives them from a Registry Demo form for string, binary, and DWORD values. Open `prjRegistry.vbp` in the VB6 IDE.
